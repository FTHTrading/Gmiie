# Source Registries

Structured source definitions organized by category.
Each JSON file contains an array of source configurations
used by the ingestion pipeline.

## Categories

- `regulators.json` — Government and regulatory agencies
- `banks.json` — Central banks and financial institutions
- `exchanges.json` — Securities and digital asset exchanges
- `rwa-platforms.json` — Tokenization and RWA platforms
- `media.json` — Financial and crypto media outlets
- `research.json` — Analytics and research firms
