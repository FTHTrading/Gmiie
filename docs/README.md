## Documentation Standards

- Use Markdown with GitHub-Flavored Markdown extensions
- Include Mermaid diagrams for architecture and flow documentation
- Mark assumptions explicitly with `> **Assumption:**` callouts
- Use status labels: `Complete`, `In Progress`, `Planned`, `Blocked`
- Keep documentation aligned with actual implementation — no aspirational claims without labels
- Update docs when behavior, architecture, or APIs change
